# NOVA — Responsive Landing Page

A modern, responsive landing page developed as part of my **SkillCraft Technology Web Development Internship — Task 1**.

The project focuses on creating an interactive navigation menu that remains fixed while scrolling and changes its appearance based on user interaction.


## 📌 Project Overview

NOVA is a modern digital experience studio landing page designed with a clean and responsive interface.

The main objective of this project was to implement an interactive navigation system with:

* Fixed navigation bar
* Scroll-based navigation styling
* Hover effects
* Active section highlighting
* Smooth scrolling
* Responsive mobile navigation
* Hamburger menu for smaller screens

## ✨ Features

### Interactive Navigation

* Fixed navigation bar visible while scrolling
* Navbar background and shadow change when scrolling
* Animated hover effects on navigation links
* Active navigation link updates based on the current section

### Responsive Design

* Desktop, tablet and mobile layouts
* Mobile hamburger navigation
* Responsive grids and typography
* Mobile-friendly buttons and sections

### Landing Page Sections

* Hero
* About
* Statistics
* Services
* Projects
* Contact
* Footer

## 🛠️ Technologies Used

* **HTML5** — Semantic page structure
* **CSS3** — Responsive design, animations and styling
* **JavaScript** — Interactive navigation and scroll behavior
